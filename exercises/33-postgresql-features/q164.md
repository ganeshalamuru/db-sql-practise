# Q164 - POSTGRESQL FEATURES

- **Difficulty:** 4 / 5
- **Learning objective:** Use a LEFT JOIN LATERAL subquery to attach each row's best related match.

## Task

For every active product, return product_id, sku, review_id, rating, and created_at for its most recent review. Include active products with no reviews, using NULL for the review columns.

## Result requirements

- **Ordering:** Order by product_id ascending.
- **Duplicates:** Duplicates are significant.

Write one PostgreSQL `SELECT` statement in `exercises/33-postgresql-features/q164.sql`. Do not modify the schema or data.
