# Q165 - POSTGRESQL FEATURES

- **Difficulty:** 5 / 5
- **Learning objective:** Build ordered nested JSONB results with jsonb_build_object and jsonb_agg.

## Task

For every delivered order, return order_id, customer_id, and items, where items is a JSONB array ordered by product_id. Each array element must be a JSONB object with keys product_id, sku, quantity, and unit_price for one order item.

## Result requirements

- **Ordering:** Order by order_id ascending.
- **Duplicates:** Duplicates are significant.

Write one PostgreSQL `SELECT` statement in `exercises/33-postgresql-features/q165.sql`. Do not modify the schema or data.
