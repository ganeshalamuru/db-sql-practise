# Q161 - POSTGRESQL FEATURES

- **Difficulty:** 1 / 5
- **Learning objective:** Use ILIKE for case-insensitive pattern matching.

## Task

Return product_id, sku, and name for every product whose name contains 'wireless', regardless of letter case.

## Result requirements

- **Ordering:** Order by product_id ascending.
- **Duplicates:** Duplicates are significant.

Write one PostgreSQL `SELECT` statement in `exercises/33-postgresql-features/q161.sql`. Do not modify the schema or data.
