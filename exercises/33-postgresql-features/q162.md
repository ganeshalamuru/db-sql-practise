# Q162 - POSTGRESQL FEATURES

- **Difficulty:** 2 / 5
- **Learning objective:** Use DISTINCT ON to select one deterministic representative row from each group.

## Task

Using DISTINCT ON, return the most recent order for each customer who has placed an order. Return customer_id, order_id, ordered_at, and status.

## Result requirements

- **Ordering:** Order by customer_id ascending.
- **Duplicates:** Duplicates are significant.

Write one PostgreSQL `SELECT` statement in `exercises/33-postgresql-features/q162.sql`. Do not modify the schema or data.
