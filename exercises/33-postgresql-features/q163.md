# Q163 - POSTGRESQL FEATURES

- **Difficulty:** 3 / 5
- **Learning objective:** Use FILTER with aggregate functions to compute conditional metrics in one grouped query.

## Task

For every supplier, return supplier_id, name, active_product_count, and inactive_product_count. Count active and inactive products with aggregate FILTER clauses, and include suppliers with no products.

## Result requirements

- **Ordering:** Order by supplier_id ascending.
- **Duplicates:** Duplicates are significant.

Write one PostgreSQL `SELECT` statement in `exercises/33-postgresql-features/q163.sql`. Do not modify the schema or data.
