# Q172 - ADVANCED SQL CHALLENGES

- **Difficulty:** 2 / 5
- **Learning objective:** Find consecutive daily activity streaks with window functions and grouped islands.

## Task

For every customer who has placed at least one order, return customer_id, streak_start_date, streak_end_date, and consecutive_order_days for that customer's longest streak of consecutive calendar days with at least one order. If a customer has equally long streaks, return the earliest one.

## Result requirements

- **Ordering:** Order by customer_id ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/35-advanced-sql-challenges/q172.sql`. Do not modify the schema or data.
