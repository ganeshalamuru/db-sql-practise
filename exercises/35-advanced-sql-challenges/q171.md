# Q171 - ADVANCED SQL CHALLENGES

- **Difficulty:** 1 / 5
- **Learning objective:** Rank aggregated product performance within a category while retaining ties.

## Task

For every active product that appears in a delivered order, return category_id, product_id, sku, delivered_revenue, and revenue_rank. delivered_revenue is the sum of quantity multiplied by unit_price from delivered orders. Rank products within each category by delivered_revenue descending, retaining ties with RANK.

## Result requirements

- **Ordering:** Order by category_id ascending, then revenue_rank ascending, then product_id ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/35-advanced-sql-challenges/q171.sql`. Do not modify the schema or data.
