# Q173 - ADVANCED SQL CHALLENGES

- **Difficulty:** 3 / 5
- **Learning objective:** Use a universal aggregate condition to identify products that are low in every stocked warehouse.

## Task

Return category_id, product_id, sku, stocked_warehouse_count, and total_quantity_on_hand for every active product stocked in at least one warehouse that is at or below its reorder_point in every warehouse where it is stocked.

## Result requirements

- **Ordering:** Order by category_id ascending, then product_id ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/35-advanced-sql-challenges/q173.sql`. Do not modify the schema or data.
