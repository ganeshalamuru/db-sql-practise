# Q175 - ADVANCED SQL CHALLENGES

- **Difficulty:** 5 / 5
- **Learning objective:** Build a customer segmentation query from independent aggregates, timestamps, and a partitioned rank.

## Task

For each city, return the top three active customers by delivered_item_total, retaining ties. Return city_id, city_name, customer_id, email, delivered_order_count, delivered_item_total, review_count, last_activity_at, and city_value_rank. Consider only active customers with at least one delivered order. delivered_item_total is the sum of quantity multiplied by unit_price in delivered orders; last_activity_at is the latest delivered ordered_at or review created_at timestamp; city_value_rank ranks customers by delivered_item_total descending within their city.

## Result requirements

- **Ordering:** Order by city_id ascending, then city_value_rank ascending, then customer_id ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/35-advanced-sql-challenges/q175.sql`. Do not modify the schema or data.
