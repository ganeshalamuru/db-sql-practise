# Q174 - ADVANCED SQL CHALLENGES

- **Difficulty:** 4 / 5
- **Learning objective:** Combine date bucketing, aggregation, and window frames for period-over-period metrics.

## Task

For each calendar month containing delivered orders, return month_start, delivered_revenue, previous_reported_month_revenue, and trailing_three_reported_month_revenue. delivered_revenue is the sum of quantity multiplied by unit_price in delivered orders. The trailing value includes the current month and the two preceding reported months.

## Result requirements

- **Ordering:** Order by month_start ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/35-advanced-sql-challenges/q174.sql`. Do not modify the schema or data.
