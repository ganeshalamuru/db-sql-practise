# Q152 - CONSTRAINTS

- **Difficulty:** 2 / 5
- **Learning objective:** Add a named multi-column UNIQUE constraint and inspect its definition.

## Task

Add a constraint named promotions_code_starts_at_unique to promotions that requires each combination of code and starts_at to be unique. Return constraint_name, constraint_type, and constraint_definition for promotions_code_starts_at_unique.

## Result requirements

- **Ordering:** No ordering is required.
- **Duplicates:** Duplicates are significant.

Write the requested SQL Server `ALTER TABLE` constraint statement or statements followed by one `SELECT` statement in `exercises/31-constraints/q152.sql`. The final SELECT must return the requested constraint metadata. The grader runs all statements in a transaction and rolls it back.
