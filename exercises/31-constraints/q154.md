# Q154 - CONSTRAINTS

- **Difficulty:** 4 / 5
- **Learning objective:** Define a multi-column CHECK constraint that protects a related pair of values.

## Task

Add a constraint named shipments_delivered_at_required that requires delivered_at to be non-NULL whenever a shipment status is delivered. Return constraint_name, constraint_type, and constraint_definition for shipments_delivered_at_required.

## Result requirements

- **Ordering:** No ordering is required.
- **Duplicates:** Duplicates are significant.

Write the requested PostgreSQL `ALTER TABLE` constraint statement or statements followed by one `SELECT` statement in `exercises/31-constraints/q154.sql`. The final SELECT must return the requested constraint metadata. The grader runs all statements in a transaction and rolls it back.
