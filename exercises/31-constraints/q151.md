# Q151 - CONSTRAINTS

- **Difficulty:** 1 / 5
- **Learning objective:** Add a named CHECK constraint and inspect its PostgreSQL definition.

## Task

Add a constraint named products_unit_price_ceiling to products that requires unit_price to be at most 1000000. Return constraint_name, constraint_type, and constraint_definition for products_unit_price_ceiling.

## Result requirements

- **Ordering:** No ordering is required.
- **Duplicates:** Duplicates are significant.

Write the requested PostgreSQL `ALTER TABLE` constraint statement or statements followed by one `SELECT` statement in `exercises/31-constraints/q151.sql`. The final SELECT must return the requested constraint metadata. The grader runs all statements in a transaction and rolls it back.
