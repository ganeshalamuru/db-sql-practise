# Q155 - CONSTRAINTS

- **Difficulty:** 5 / 5
- **Learning objective:** Define a named cross-column CHECK constraint for a time-window business rule.

## Task

Add a constraint named promotions_discount_window_limit to promotions that requires a promotion to last no more than 730 days. Return constraint_name, constraint_type, and constraint_definition for promotions_discount_window_limit.

## Result requirements

- **Ordering:** No ordering is required.
- **Duplicates:** Duplicates are significant.

Write the requested SQL Server `ALTER TABLE` constraint statement or statements followed by one `SELECT` statement in `exercises/31-constraints/q155.sql`. The final SELECT must return the requested constraint metadata. The grader runs all statements in a transaction and rolls it back.
