# Q153 - CONSTRAINTS

- **Difficulty:** 3 / 5
- **Learning objective:** Add and validate a named foreign-key constraint after it is created.

## Task

Add a NOT VALID foreign-key constraint named orders_promotion_fk_not_valid from orders.promotion_id to promotions.promotion_id, then validate it. Return constraint_name, constraint_type, and is_validated for orders_promotion_fk_not_valid.

## Result requirements

- **Ordering:** No ordering is required.
- **Duplicates:** Duplicates are significant.

Write the requested PostgreSQL `ALTER TABLE` constraint statement or statements followed by one `SELECT` statement in `exercises/31-constraints/q153.sql`. The final SELECT must return the requested constraint metadata. The grader runs all statements in a transaction and rolls it back.
