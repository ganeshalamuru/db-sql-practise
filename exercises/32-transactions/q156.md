# Q156 - TRANSACTIONS

- **Difficulty:** 1 / 5
- **Learning objective:** Make and inspect a single change inside an explicit transaction.

## Task

Start a transaction, set customer_id 1 to status 'suspended', and return customer_id, email, and status for that customer before rolling back the transaction.

## Result requirements

- **Ordering:** No ordering is required.
- **Duplicates:** Duplicates are significant.

Write a SQL Server transaction in `exercises/32-transactions/q156.sql`. Start with `BEGIN TRANSACTION`, make the requested changes, return the requested rows with a final `SELECT`, and finish with `ROLLBACK TRANSACTION` so the practice database remains unchanged. The grader also rolls back the exercise transaction.
