# Q160 - TRANSACTIONS

- **Difficulty:** 5 / 5
- **Learning objective:** Combine row locking and a CTE with an atomic multi-row inventory transfer.

## Task

Start a transaction and use a CTE that locks the product_id 1 inventory rows for warehouse_id 1 and warehouse_id 2. Transfer 5 units from warehouse_id 1 to warehouse_id 2, then return warehouse_id, product_id, quantity_on_hand, and reorder_point for those two rows before rolling back the transaction.

## Result requirements

- **Ordering:** Order by warehouse_id ascending.
- **Duplicates:** Duplicates are significant.

Write a SQL Server transaction in `exercises/32-transactions/q160.sql`. Start with `BEGIN TRANSACTION`, make the requested changes, return the requested rows with a final `SELECT`, and finish with `ROLLBACK TRANSACTION` so the practice database remains unchanged. The grader also rolls back the exercise transaction.
