# Q157 - TRANSACTIONS

- **Difficulty:** 2 / 5
- **Learning objective:** Insert a row inside a transaction and inspect it before rollback.

## Task

Start a transaction, insert a supplier with name 'Transaction Practice Supplier', contact_email 'transaction-practice-supplier@example.test', and country_id 1. Return name, contact_email, and country_id for the inserted supplier before rolling back the transaction.

## Result requirements

- **Ordering:** No ordering is required.
- **Duplicates:** Duplicates are significant.

Write a PostgreSQL transaction in `exercises/32-transactions/q157.sql`. Start with `BEGIN`, make the requested changes, return the requested rows with a final `SELECT`, and finish with `ROLLBACK` so the practice database remains unchanged. The grader also rolls back the exercise transaction.
