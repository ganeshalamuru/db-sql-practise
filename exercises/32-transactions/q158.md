# Q158 - TRANSACTIONS

- **Difficulty:** 3 / 5
- **Learning objective:** Use a savepoint to undo part of a transaction before inspecting the restored state.

## Task

Start a transaction and create a savepoint named product_price_before_change. Increase product_id 1's unit_price by 10, then roll back to the savepoint. Return product_id, sku, and unit_price for product_id 1 before rolling back the transaction.

## Result requirements

- **Ordering:** No ordering is required.
- **Duplicates:** Duplicates are significant.

Write a PostgreSQL transaction in `exercises/32-transactions/q158.sql`. Start with `BEGIN`, make the requested changes, return the requested rows with a final `SELECT`, and finish with `ROLLBACK` so the practice database remains unchanged. The grader also rolls back the exercise transaction.
