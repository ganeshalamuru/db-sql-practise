# Q159 - TRANSACTIONS

- **Difficulty:** 4 / 5
- **Learning objective:** Apply related inventory changes atomically within one transaction.

## Task

Start a transaction and transfer 25 units of product_id 1 from warehouse_id 1 to warehouse_id 2. Return warehouse_id, product_id, and quantity_on_hand for those two inventory rows before rolling back the transaction.

## Result requirements

- **Ordering:** Order by warehouse_id ascending.
- **Duplicates:** Duplicates are significant.

Write a SQL Server transaction in `exercises/32-transactions/q159.sql`. Start with `BEGIN TRANSACTION`, make the requested changes, return the requested rows with a final `SELECT`, and finish with `ROLLBACK TRANSACTION` so the practice database remains unchanged. The grader also rolls back the exercise transaction.
