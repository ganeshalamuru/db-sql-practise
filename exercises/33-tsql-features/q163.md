# Q163 - T-SQL FEATURES

- **Difficulty:** 3 / 5
- **Learning objective:** Use conditional CASE with aggregate functions to compute conditional metrics in one grouped query.

## Task

For every supplier, return supplier_id, name, active_product_count, and inactive_product_count. Count active and inactive products using conditional CASE aggregates, and include suppliers with no products.

## Result requirements

- **Ordering:** Order by supplier_id ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/33-tsql-features/q163.sql`. Do not modify the schema or data.
