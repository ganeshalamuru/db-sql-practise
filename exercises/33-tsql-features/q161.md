# Q161 - T-SQL FEATURES

- **Difficulty:** 1 / 5
- **Learning objective:** Use TOP WITH TIES for deterministic top-N rank queries.

## Task

Return product_id, sku, name, and unit_price for the top 5 most expensive products. If there are ties for the 5th price, return all tied products using TOP WITH TIES.

## Result requirements

- **Ordering:** Order by unit_price descending, then product_id ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/33-tsql-features/q161.sql`. Do not modify the schema or data.
