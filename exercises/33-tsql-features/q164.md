# Q164 - T-SQL FEATURES

- **Difficulty:** 4 / 5
- **Learning objective:** Use an OUTER APPLY subquery to attach each row's best related match.

## Task

For every active product, return product_id, sku, review_id, rating, and created_at for its most recent review using OUTER APPLY. Include active products with no reviews, using NULL for the review columns.

## Result requirements

- **Ordering:** Order by product_id ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/33-tsql-features/q164.sql`. Do not modify the schema or data.
