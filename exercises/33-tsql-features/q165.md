# Q165 - T-SQL FEATURES

- **Difficulty:** 5 / 5
- **Learning objective:** Split delimited strings into table rows using STRING_SPLIT.

## Task

Using STRING_SPLIT, parse the comma-separated tag list 'electronics,kitchen,laptops,books' into individual rows. Return the distinct trimmed tags as tag.

## Result requirements

- **Ordering:** Order by tag ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/33-tsql-features/q165.sql`. Do not modify the schema or data.
