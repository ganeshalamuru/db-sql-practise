# Q166 - QUERY REWRITING

- **Difficulty:** 1 / 5
- **Learning objective:** Use a semi-join with EXISTS instead of joining only to test for related rows.

## Task

Using EXISTS, return product_id, sku, and name for active products that have at least one five-star review.

## Result requirements

- **Ordering:** Order by product_id ascending.
- **Duplicates:** Duplicates are significant.

Write one PostgreSQL `SELECT` statement in `exercises/34-query-rewriting/q166.sql`. Do not modify the schema or data.
