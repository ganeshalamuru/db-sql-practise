# Q167 - QUERY REWRITING

- **Difficulty:** 2 / 5
- **Learning objective:** Rewrite a correlated count test as a grouped join with HAVING.

## Task

Using a join, GROUP BY, and HAVING rather than a correlated subquery, return customer_id, email, and order_count for customers who have placed at least three orders.

## Result requirements

- **Ordering:** Order by customer_id ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/34-query-rewriting/q167.sql`. Do not modify the schema or data.
