# Q169 - QUERY REWRITING

- **Difficulty:** 4 / 5
- **Learning objective:** Combine separately aggregated metrics without a join fan-out.

## Task

For every active customer, return customer_id, email, order_count, review_count, and delivered_item_total. order_count is the number of all orders, review_count is the number of reviews, and delivered_item_total is the sum of quantity multiplied by unit_price for delivered orders, using 0 for missing metrics. Build independent aggregate result sets before joining them to customers.

## Result requirements

- **Ordering:** Order by customer_id ascending.
- **Duplicates:** Duplicates are significant.

Write one SQL Server `SELECT` statement in `exercises/34-query-rewriting/q169.sql`. Do not modify the schema or data.
