# Q168 - QUERY REWRITING

- **Difficulty:** 3 / 5
- **Learning objective:** Pre-aggregate independent one-to-many relationships before joining their results.

## Task

Return category_id, category_name, active_product_count, and active_inventory_units for every category. Count active products and sum the quantity_on_hand of those active products across warehouses without multiplying either metric through a direct products-to-inventory join. Use 0 when a category has no matching rows.

## Result requirements

- **Ordering:** Order by category_id ascending.
- **Duplicates:** Duplicates are significant.

Write one PostgreSQL `SELECT` statement in `exercises/34-query-rewriting/q168.sql`. Do not modify the schema or data.
